## QR Code Integration
1. Deploy your site to Vercel and copy the public URL (e.g., `https://your-site.vercel.app`).
2. Generate a QR code pointing to that URL using any QR generator (or Canva).
3. Print the QR code on invitations.

## Tips
- Use a short URL if you want a cleaner QR code.
- Test the QR code on both iPhone and Android before printing.
